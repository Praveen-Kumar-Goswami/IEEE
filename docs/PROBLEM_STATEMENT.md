# Problem statement

Smart Dressing for Noninvasive Monitoring of Surgical Site Infection Indicators.

Frequent dressing changes can expose healing tissue to handling and disturb the local wound environment. Changes in localized temperature, moisture, and related indicators may provide useful monitoring signals. A smart dressing can aim to observe selected environmental changes without repeatedly removing the dressing. The prototype should demonstrate how these signals can be captured and presented using a safe simulated wound setup.

The dressing monitors localized temperature and moisture or humidity and tracks changes in the wound-dressing environment over time. It provides a simple visual or electronic indication of predefined changes. Demonstration uses a safe simulated wound model. The prototype is framed as noninvasive monitoring of selected indicators and does not claim to independently diagnose surgical-site infection.

The design emphasizes low-profile sensing and the ability to collect measurements without disturbing the simulated dressing. Predefined changes in temperature or moisture can be introduced during testing to evaluate responsiveness. Data logging and trend visualization show how multiple indicators can be reviewed together.

This stays inside monitoring and early-warning demonstration boundaries. It must not be used to make clinical infection decisions.
